#DSP and DFT Experiment
This project implements basic signal processing ideas in Python. 

##Features: 
- Generates a constant signal
- Generates an impulse signal
- Generates sine and cosine signals
- Signal addition (superposition)
- Visualization using matplotlib


##How to run

Run the main file:

Follow the prompts to generate and plot signals

##Requirements

- Python 3
- Matplotlib

Install Matplotlib:
pip install matplotlib
